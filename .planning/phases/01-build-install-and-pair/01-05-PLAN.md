<objective>
Turn the pushed code into an unsigned `.ipa` on a GitHub Mac runner, twice, from the same commit, record what it cost, and leave both files ready for the phone. This is the first time the app target and the Core package are compiled by Apple's toolchain, so expect to spend one or two builds fixing what Linux could not see.

Phase goal (ROADMAP, verbatim): User can build the iPhone app on GitHub Actions without a Mac, install it with AltStore, pair it with the PC by typing address and code, and see it reach the PC over plain HTTP.

Purpose: BLD-03 (manual Mac build, unsigned ipa, early failure on a missing permission text), BLD-04 (artifact carries no profile and no extra bundles so AltStore can re-sign it), BLD-06 (build number is the run number), BLD-07 (minutes measured and recorded).
Output: `.github/workflows/ios-build.yml`, two verified ipa artifacts, `01-GATE.md` skeleton with the builds table.

Planning for scarce Mac minutes (STATE.md: about 25 builds a month until measured): everything that can fail on Linux already did in Plans 01 to 04. The two required builds are A (first install and refresh test) and B (install-over test, differs only in build number). Any extra dispatch is a fix build and is capped at three in total for the first success. Dispatching is always a deliberate action step; verify blocks only inspect a run by its recorded id, so re-verifying never spends a Mac minute.
</objective>
